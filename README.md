# Al Wajer Pharma ERP v2.4.1

Enterprise Resource Planning system for Al Wajer Pharmaceutical Industry LLC.

## Features
- Dashboard with charts and KPIs
- Manufacturing, Inventory, Sales, Procurement modules
- Formulations management with AI ingredient import
- AI Command center (Gemini 3.1 Pro)
- Industrial Studio with AI image generation
- Cost & Sale Calculator with quotation preview
- Firebase Authentication (Google Sign-In)
- Firestore real-time database
- Audit logging

## Tech Stack
- React 18 + TypeScript
- Vite
- Tailwind CSS v4
- Firebase (Auth, Firestore, Storage)
- Google Gemini AI
- Recharts
- Framer Motion

## Environment Variables
```
VITE_GEMINI_API_KEY=your_gemini_api_key
```

## Deploy
Connect this repo to Vercel with framework preset "Vite".
